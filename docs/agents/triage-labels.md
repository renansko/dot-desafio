# Labels de triagem

| Papel e label | Significado |
| --- | --- |
| `needs-triage` | Aguarda avaliação inicial |
| `needs-info` | Aguarda esclarecimento |
| `ready-for-agent` | Especificada e pronta para implementação AFK |
| `ready-for-human` | Requer implementação humana |
| `wontfix` | Não será implementada |

Publicar as três issues com `needs-triage`. AFK descreve a autonomia prevista, não dispensa triagem nem remove bloqueadores.
